# Version 1.3.5

## Release acceptance fixture

Version 1.3.4's release workflow stopped twice at the first Chromium database
keyboard case. Vite discovered `react-helmet-async` after browser startup and
reloaded the fixture during that interaction. No 1.3.4 image was published.
The immutable `v1.3.4` tag remains on its original source revision.

The database browser runner now explicitly prebundles that dependency before
starting Playwright, matching the preparation used by the other synthetic
browser runners. Focus and save assertions, timeouts, retries and production
application code are unchanged. A cold-cache CI-mode run passed all 27 database
keyboard cases across Chromium, Firefox and WebKit without a late Vite reload.

## Security dependency correction and deployment

This release carries the [1.3.4 picomatch correction](v1.3.4.md): the scoped
Excalidraw Sass override removes its vulnerable picomatch production dependency
chain. Development tooling still depends on unpatched picomatch; other existing
low/moderate audit findings remain outside this correction. No audit exception
or disabled gate is introduced.

Replace both affected 1.3.3 API and collaboration images with the verified
1.3.5 image by immutable digest using [the deployment runbook](../../../../docs/DEPLOYMENT.md).
There is no schema or environment-contract change. Preserve the accepted native
backup producer, timer, transport and retention history, and retain the recorded
1.3.3 image/state for the documented rollback window.

The actual deployment receipt belongs in
`docs/verification/picomatch-2026-11-17.md` after production acceptance.
