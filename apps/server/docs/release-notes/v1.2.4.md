# Docmost v1.2.4 release notes

This release supersedes the `v1.2.3` tag, whose release workflow stopped before
publishing a container image. No production image was published for `v1.2.3`.

`v1.2.4` contains the same product, database, backup, and rollback changes as
`v1.2.3`. Installations upgrading from `v1.2.2` or earlier must follow the
[v1.2.3 upgrade and rollback contract](./v1.2.3.md) in full, substituting the
`v1.2.4` tag, immutable image digest, and OCI version label wherever that
contract names `v1.2.3`.

## Release verification correction

- The Firefox media acceptance scenario now waits for the user-visible
  read-only document and media nodes. It no longer requires the internal
  collaborative `.editor-container`, which is not part of the read-mode product
  contract and could remain absent while the valid static document was already
  rendered.
- The full release workflow, including PostgreSQL migration smoke, editor and AI
  browser acceptance, AI context, embedded RAG Sync recovery, and image
  provenance checks, remains mandatory before publication.

The Docker release workflow accepts only the tag `v1.2.4` for manifests whose
version is `1.2.4`. Deploy only the registry digest whose OCI revision equals
the tagged commit; do not deploy the mutable tag or `latest`.
