# Version 1.3.4

## Security dependency correction

The production dependency audit found `picomatch@2.3.2` through
`@excalidraw/excalidraw@0.18.0-3a5ef40 -> sass@1.51.0 -> chokidar@3.6.0`
and its `anymatch` / `readdirp` dependencies.
[GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)
describes repeated-extglob regular expression denial of service and, as checked
on 17 November 2026, has no patched upstream picomatch release.

A parent-scoped root override selects `sass@1.79.4` only for Excalidraw.
Its Chokidar 4 dependency uses Readdirp 4 without picomatch. This preserves the
existing Excalidraw version and Immutable 4 resolution policy; it adds no native
watcher dependency. The modern and legacy Sass compilation APIs and the actual
watcher dependency closure are covered by the dependency security suite.
The lockfile changes are confined to this chain and its peer snapshots.
No audit exception or disabled gate is introduced.

Development tooling still uses picomatch, which remains unpatched upstream.
The production audit result must not be described as a clean all-dependency audit.
Other existing low/moderate findings are outside this correction.

## Deployment

The installed 1.3.3 image was inspected directly: picomatch 2.3.2 and Sass 1.51.0
are present in both API and collaboration containers' production dependency
store. The Docker runtime stage materializes production lockfile dependencies,
including this client dependency chain. Replace both services with the verified
1.3.4 image by immutable digest using [the deployment runbook](../../../../docs/DEPLOYMENT.md).
No schema or environment migration is introduced by this release.

Keep the accepted native backup tool at revision
`9f8b67a72dceae1e79b14f2d8e40a797e0325eba`, its configuration, the 05:00 MSK
timer and existing transport/retention history. Before deployment, verify the
current baseline, off-host backup and isolated restore evidence. Roll back the
application image/state using the recorded 1.3.3 baseline if acceptance fails;
do not roll back the native scheduled producer.

The deployment receipt belongs in `docs/verification/picomatch-2026-11-17.md`
after actual production acceptance.
