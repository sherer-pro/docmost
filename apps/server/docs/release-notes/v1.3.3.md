# Docmost v1.3.3 release notes

`v1.3.3` retains the complete MCP readers introduced in `v1.3.2` and bounds
saved-version comparison before it can block API liveness. Large comparisons
return linear block summaries with `precise=false`; their changes and character
counts are approximate. Complete source text remains available through
`getPageVersion` and `getPage` continuations. Small comparisons retain precise
changes, and unchanged large documents return an exact empty diff.

The administrator guide contract is v46 across all twelve locales. Existing
capabilities, cursor formats, ACL, AI exclusions and the opt-in permission model
are unchanged. This release adds no database migration.

Publish the exact `v1.3.3` tag and select its immutable
`shererpro/docmost:1.3.3` registry digest with matching OCI version and revision.
Keep the previous image and volume through the documented production acceptance
and rollback boundary. See [v1.3.2](./v1.3.2.md) for the full reader contract and
the [deployment runbook](../../../../docs/DEPLOYMENT.md) for publication and
deployment checks.
