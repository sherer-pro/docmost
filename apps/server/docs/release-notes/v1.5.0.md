# Docmost v1.5.0

Space-scoped MCP clients can create pages with an assignee, status and AI role,
write inline tags in Markdown and replace an active Draw.io attachment with an
editable model. Read the [wire contract](../../../../docs/AI_ASSISTANT_AND_RAG.md#inbound-mcp-writes)
for input limits, preview fields, replay and file verification.

## Upgrade from v1.4.0

Follow the [production deployment procedure](../../../../docs/DEPLOYMENT.md).
Deploy the collaboration service and API from the same verified image, in that
order, before reopening ingress. This release uses the existing receipt schema
and key capabilities. Draw.io replacement needs both page content write and
image upload. Allow at least 4,210,692 bytes per request on the MCP route.

## Verify and recover

Check `initialize` and `tools/list` with a space-scoped key. The isolated MCP
write suite exercises the full write cycle and byte-for-byte readback using
synthetic data. After an interrupted request, use the original operation ID to
look up its result. A replacement creates a new attachment and preserves the
previous file. Until ingress is reopened, the previous image and existing
database remain compatible. After new writes, retain the live database, files
and receipts and follow the deployment guide's recovery procedure.
