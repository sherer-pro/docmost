# Docmost 1.5.1

MCP publishing clients can add another editable Draw.io diagram at the end
of a page with `editPageContent` and `edit.kind = "appendDrawio"`. Each
diagram has its own attachment. Use the existing preview, commit and status
flow and verify the new file through chunked readback.

`appendBlock`, `insertBlock` and `replaceBlock` now accept a Markdown pipe
table with header and body cells, inline links and native tags.
An unchanged document keeps its content-edit preview hash when collaboration
updates the page-row timestamp. A new edit still conflicts with a changed
document revision.

The release workflow publishes a SHA-specific deployment candidate while CI
is running. After all gates pass, it promotes that exact digest to the version
and latest tags.

See the [MCP write contract](../../../../docs/AI_ASSISTANT_AND_RAG.md#inbound-mcp-writes).
Upgrade the collaboration server and API together using the
[production deployment procedure](../../../../docs/DEPLOYMENT.md).
