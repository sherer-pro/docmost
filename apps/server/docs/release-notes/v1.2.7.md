# Docmost v1.2.7 release notes

`v1.2.7` is an AI assistant usability release with a profile-first composer,
responsive panel behavior, and a larger assistant-profile icon catalog. It
supersedes `v1.2.6`.

## AI assistant panel and composer

- The assistant uses one edge-to-edge composer surface with visible context,
  profile selection, Chat/Agent mode, Markdown tools, status, and send or stop
  actions kept in a stable footer.
- Desktop users can resize the panel from 360 to 600 pixels with pointer or
  keyboard controls. The panel switches between docked and overlay placement
  without remounting the composer, while narrow layouts use a full-screen flow
  without horizontal overflow.
- Profile options expose descriptions and preserve the active profile's
  identity and availability when live profile data changes. The composer and
  chat history now share the same spacing and width rhythm.
- Add, profile, and secondary composer actions adapt at narrow widths while
  retaining keyboard access, focus recovery, and accessible control names.

## Assistant profiles and editor polish

- Assistant profiles now offer 32 stable Tabler icon choices. The shared API
  contract, server validation, settings editor, chat renderer, administrator
  guide, and all 12 supported locales use the same catalog.
- The tag popover's "Find this tag in the space" action keeps its behavior and
  accessible label but uses a compact neutral treatment instead of a prominent
  full-width action.

## Maintenance, upgrade, and rollback

- The maintenance audit no longer exposes internal AI panel constants or
  unused client type aliases as public contracts, and its reviewed Knip
  baseline reflects the profile option type that is now consumed by the panel.
- There are no new database migrations or environment-contract changes between
  `v1.2.6` and `v1.2.7`. Operators must still create and verify a coordinated
  backup, rehearse restore, and complete the documented production preflight
  before changing the running image.
- Before accepting the deployment, verify sign-in, collaboration, the AI panel
  in docked, overlay, focus, and narrow layouts, profile selection and icons,
  Chat/Agent controls, and the expected Docker image provenance.
- Rollback before acceptance uses the previous immutable `v1.2.6` image digest
  and does not require a database rollback. After acceptance, follow the normal
  coordinated rollback policy and preserve the deployment receipts.

The Docker release workflow accepts only tag `v1.2.7` for manifests whose
version is `1.2.7`. Deploy only the registry digest whose OCI
`org.opencontainers.image.version` is `1.2.7` and whose OCI revision equals the
tagged commit.
